Desk Calendar 바탕화면 캘린더

Windows 바탕화면에 붙어 있는 캘린더 위젯입니다. 다른 창 뒤에 항상 떠 있어 일정을 바로 볼 수 있고, Google 캘린더와 iCloud 캘린더의 일정을 양방향으로 동기화합니다.

주요 기능

  • 바탕화면 고정 위젯: 작업 표시줄에 나타나지 않고 트레이에서 관리, "바탕화면 보기"에도 유지
  • 월간·주간 보기, 주차 표시, 공휴일·음력 표시
  • 날짜 옆 말풍선으로 일정 추가: 반복, 위치, 중요도, 알람
  • 일정 고정과 D-Day, 완료 체크
  • Windows 알림으로 일정 알람, 다시 알림
  • Google 캘린더·iCloud 캘린더 양방향 동기화, 여러 계정 연결
  • 일정 내보내기·가져오기(.ics)와 전체 백업·복원

다운로드

설치 파일 받기 (DeskCalendarSetup.exe)

  • Windows 10(1809 이상)·Windows 11, 64비트. 실행에 필요한 구성 요소가 포함되어 있어 따로 설치할 것이 없습니다.
  • 처음 실행할 때 "Windows의 PC 보호" 창이 나오면 추가 정보 → 실행을 눌러 주세요. 코드 서명 인증서가 없는 개인 개발 앱이라 표시되는 안내입니다.
  • 설치한 뒤에는 새 버전이 나오면 앱이 알려 주고 바로 업데이트할 수 있습니다.
  • 삭제는 Windows 설정 → 앱 → 설치된 앱에서 "바탕화면 캘린더"를 제거하면 됩니다.

Google 캘린더 데이터 사용

Google 계정을 연결하면 Desk Calendar는 Google Calendar API로 캘린더 목록과 일정을 읽고, 위젯에서 추가·수정·삭제한 일정을 Google 캘린더에 반영합니다. 계정을 구분해 보여 주기 위해 Google 계정의 이메일 주소를 사용합니다.

모든 데이터는 사용자의 PC에만 저장되며 개발자의 서버로 전송되지 않습니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.
