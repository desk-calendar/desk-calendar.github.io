개인정보처리방침

시행일: 2026년 10월 4일

Desk Calendar(바탕화면 캘린더, 이하 "앱")는 Windows PC에서 동작하는 캘린더 위젯입니다. 앱에는 개발자가 운영하는 서버가 없으며, 앱이 다루는 정보는 모두 사용자의 PC 안에만 저장됩니다.

1. 처리하는 정보

  • 일정과 설정: 사용자가 입력하거나 동기화한 일정, 캘린더 목록, 앱 설정
  • Google 계정 연결 시: Google 캘린더의 캘린더 목록과 일정, 계정 표시용 이메일 주소, Google이 발급한 로그인 토큰
  • iCloud 계정 연결 시: Apple ID와 사용자가 입력한 앱 전용 암호, iCloud 캘린더의 일정

2. 이용 목적

위 정보는 위젯에 일정을 표시하고, 위젯에서 바꾼 일정을 사용자의 Google·iCloud 캘린더와 동기화하고, 일정 알람을 보여 주는 데에만 사용합니다. 광고, 분석, 프로필 작성에는 사용하지 않습니다.

3. 저장과 보호

  • 모든 정보는 사용자 PC의 %LOCALAPPDATA%\DeskCalendar\data.db 파일 하나에 저장됩니다.
  • 로그인 토큰과 앱 전용 암호는 Windows 데이터 보호(DPAPI)로 암호화해, 같은 Windows 사용자 계정에서만 읽을 수 있습니다.
  • 앱은 Google(googleapis.com)과 Apple iCloud(icloud.com) 서버하고만 통신합니다. 그 밖의 곳으로 정보를 보내지 않습니다.

4. 제3자 제공

개발자는 사용자의 정보에 접근할 수 없으며, 어떤 정보도 판매하거나 제3자에게 제공하지 않습니다.

5. Google 사용자 데이터

Desk Calendar's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

앱이 요청하는 권한은 Google 캘린더 읽기·쓰기(https://www.googleapis.com/auth/calendar)와 계정 이메일 확인(openid, email)입니다.

6. 보관 기간과 삭제

  • 앱 설정의 "연결 해제"를 누르면 해당 계정의 정보가 PC에서 삭제되고 Google 로그인 토큰이 폐기됩니다.
  • 앱을 제거할 때 "일정·설정·연결한 계정 정보도 모두 삭제"(기본 선택)를 두면 앱이 만든 파일과 정보가 모두 삭제됩니다.
  • Google 계정의 서드파티 액세스 화면에서도 언제든 앱의 권한을 철회할 수 있습니다.

Privacy Policy (English summary)

Desk Calendar is a Windows desktop calendar widget. It has no server of its own: all data stays on the user's PC in a single file, with sign-in tokens and app-specific passwords encrypted by Windows DPAPI.

When a Google account is connected, the app reads and writes the user's Google Calendar data through the Google Calendar API and reads the account's email address to label the account. This data is used only to show the calendar in the widget, sync changes made in it, and show event reminders. It is never sent to the developer or any third party, and never sold or used for advertising.

Desk Calendar's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Disconnecting an account removes its data from the PC and revokes the Google token; uninstalling with the default "delete all data" option removes all app data. Access can also be revoked at Google Account permissions. Contact: moon.dev.prog@gmail.com
